HOW TO USE

소액티켓 이용안내

이용 목적을 선택하고 조건을 확인한 뒤 결과를 직접 점검하는 과정을 순서대로 안내합니다.

☷
01 / STEP BY STEP

이용 절차를 네 단계로 살펴보세요

상품권 구매와 매입은 각각 확인할 내용이 다릅니다. 무엇을 진행하려는지 먼저 정리하면 필요한 정보를 더 빠르게 찾을 수 있습니다.

01

서비스 선택

휴대폰 결제·신용카드 구매·상품권 매입 중 목적을 정합니다.

02

조건 확인

실제 비용, 사용 가능 여부와 상품권 상태를 확인합니다.

03

신청·접수

안내된 절차에 따라 필요한 정보를 정확하게 입력합니다.

04

결과 확인

승인과 발급, 취소 또는 입금 결과를 직접 확인합니다.

02 / BEFORE YOU START

이용 전에 확인할 체크리스트

상품권 이름, 발행처, 사용처, 액면금액과 구매 시 최종 금액을 먼저 확인해 주세요. 결제수단별 이용 가능 여부가 다를 수 있으므로 화면에서 적용되는 조건도 살펴보는 것이 좋습니다.

결제 후 카드대금이나 통신요금이 언제 청구되는지, 무이자 또는 수수료 조건이 어떤지 확인하는 것도 중요합니다. 안내받은 정보가 실제 결제화면과 다르다면 먼저 문의해 주세요.

03 / AFTER PAYMENT

거래 결과는 직접 확인해 주세요

결제 승인과 상품권 발급, 매입 접수와 최종 입금은 각각 다른 단계일 수 있습니다. 승인 문자나 접수 완료 메시지만으로 모든 절차가 끝났다고 생각하지 않는 것이 좋습니다.

결제 오류나 취소가 필요한 상황에서는 주문번호와 결제 승인 내역, 구매처의 취소 처리 상태를 구분해 확인하고, 확인된 정보를 바탕으로 해당 업체에 문의해 주세요.

A

구매 결과

상품권 발급 여부와 주문내역 확인

B

취소 결과

요청이 아닌 취소 완료 표시 확인

C

입금 결과

실제 은행 계좌의 입금 금액 확인

04 / PERSONAL INFORMATION

상품권 번호와 개인정보 관리

인증번호, 카드 비밀번호, 상품권 PIN·바코드처럼 실제 이용에 필요한 정보는 누구나 접근할 수 있는 곳에 올리지 않는 것이 좋습니다.

처음 상담을 요청할 때는 어떤 서비스를 알아보는지와 현재 어떤 문제가 있는지부터 이야기하세요. 추가 정보가 필요한 경우에는 공식 접수 경로와 실제 운영 주체를 먼저 확인하고 전달해 주세요.
