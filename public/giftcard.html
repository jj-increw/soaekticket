모바일상품권 매입 안내

선물받은 쿠폰부터 지류상품권까지, 지금 보유한 상품권이 어떤 상태인지 먼저 알아보세요.

✧
01 / OVERVIEW

보유한 상품권부터 정확히 구분해 주세요

매입을 알아보려면 상품권의 발행처와 종류, 권종, 금액 및 수량부터 확인하는 것이 좋습니다. 문자로 받은 모바일 금액권과 특정 상품으로 교환하는 교환권은 사용 방법과 매입 가능 여부가 다를 수 있습니다.

이미 보유한 상품권이라고 해서 언제나 매입할 수 있는 것은 아닙니다. 확인할 수 있는 상태와 매입업체가 취급하는 종류가 일치하는지 먼저 살펴보세요.

01

모바일 금액권

표시 금액, 발행처, 현재 잔액 확인

02

교환권

교환 대상 상품과 이용 상태 확인

03

지류상품권

실물 상태와 권종, 확인 방법 점검

02 / GIFT CARD TYPES

모바일과 지류상품권의 차이

모바일상품권은 문자, 앱 선물함 또는 바코드로 전달되는 경우가 많습니다. 해당 쿠폰이 사용되지 않았는지, 앱에 등록된 상태인지, 발행처 조회에서 현재 어떤 상태로 나오는지 확인할 필요가 있습니다.

지류상품권은 실물의 보관 상태와 발행처, 상품권에 적힌 정보의 식별 여부가 중요할 수 있습니다. 훼손되거나 일부가 보이지 않는 상품권은 별도의 확인 절차가 필요할 수 있습니다.

03 / VALIDITY

유효기간과 사용 상태 점검

선물함에 상품권이 남아 있더라도 실제로는 이미 사용되었거나 일부 사용된 상태일 수 있습니다. 매입 신청 전에 발행처에서 현재 상태를 조회할 수 있는지 확인해 주세요.

유효기간이 지난 상품권은 매입이 어려울 수 있지만 발행처의 연장·환불 정책과 매입업체의 취급 조건은 다른 문제입니다. 정확한 상태를 구분해 문의하는 것이 좋습니다.

미사용

등록·사용 기록을 확인해 주세요

발행처 기준으로 미사용 여부를 먼저 확인합니다.

등록됨

이미 캐시나 포인트로 전환됐는지 확인

등록 상태에 따라 매입 조건이 달라질 수 있습니다.

기간 만료

발행처 연장·환불 가능 여부 확인

매입 가능 여부와 별도로 살펴봐야 합니다.

04 / BUYBACK CONDITIONS

매입 금액은 어떻게 정해지나요?

상품권에 적힌 액면금액과 실제 안내되는 매입 금액은 다를 수 있습니다. 상품권 종류와 권종, 상태, 접수 시점의 조건에 따라 적용 비율이 달라질 수 있습니다.

매입률만 보지 말고 최종 입금 예정액이 얼마인지 확인하는 것이 중요합니다. 여러 종류를 함께 접수한다면 상품권별 적용 금액과 합계를 구분해 확인해 주세요.

05 / RESULT

매입 신청 후 입금 확인

매입 신청이 접수됐다는 안내와 상품권 확인이 끝났다는 뜻은 다릅니다. 매입처에서 상품권 상태를 확인한 뒤 실제 매입 가능 여부와 입금 예정액이 확정될 수 있습니다.

입금 완료 안내를 받았다면 고객님의 계좌에 실제 입금된 금액과 시간을 확인해 주세요. 입금이 예상보다 늦다면 중복 신청 대신 기존 신청번호와 상품권 종류를 정리해 문의하는 것이 좋습니다.

PIN 보호: 상품권 번호나 바코드는 공개 게시판에 올리지 말고 공식적인 절차를 확인한 뒤 전달해 주세요.
