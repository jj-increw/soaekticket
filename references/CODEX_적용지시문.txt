# 소액티켓 V4 프로젝트 Codex 작업 지시

새 소액티켓 프로젝트의 public/index.html, mobile-payment.html, credit-card.html, giftcard.html, guide.html, faq.html 과 assets/site.css, assets/site.js를 확인하세요.

1. 총 6개 페이지가 독립된 HTML로 열리는지 확인합니다. 첫 화면은 index.html입니다.
2. PC 메가메뉴 6열 클릭 → 선택 열 강조 → 하위 메뉴 클릭 시 각 상세페이지/해당 앵커로 정상 이동을 확인합니다.
3. 모바일 햄버거 메뉴 → 하위 아코디언 → 링크 이동을 확인합니다.
4. 메인 배너 6장 이동·일시정지 기능을 확인합니다.
5. 각 페이지 FAQ, 비교표, TOP, 푸터 링크를 확인합니다.
6. 실제 채널톡 주소가 정해지기 전에는 허위 링크를 만들지 않고 FAQ 고객센터 안내로 연결한 상태를 유지합니다.
7. 공식 도메인과 상담 주소가 확정되기 전에는 noindex,nofollow를 유지합니다.
8. 확인되지 않은 상품권 매입 비율, 카드 혜택, 입금 시간을 임의로 쓰지 마세요.
9. 배포는 하지 말고 1440px PC / 390px·375px·320px 모바일 스크린샷과 테스트 결과를 먼저 보여 주세요.
10. 이 프로젝트는 광속페이/비상구24와 별개입니다. 다른 사이트 소스나 기존 파일을 수정하지 마세요.
